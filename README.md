## What it does

`main.py` (Python standard library only, deterministic, offline) writes one
original line of office comedy to `/output/entry.txt`:

> I declined a meeting about the meeting and got invited to a meeting to discuss why I declined the meeting.

## Run it

```sh
python3 main.py
```

For local testing, set `MAKEFUN_OUTPUT` to choose where the joke is written:

```sh
MAKEFUN_OUTPUT=/tmp/entry.txt python3 main.py
```
